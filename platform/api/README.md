# GAP Platform API

## Ishga tushirish

### 1. O'rnatish
npm install

### 2. .env sozlash
DATABASE_URL=postgresql://...
PORT=3847

### 3. Bazani tayyorlash (bir marta)
npm run seed

### 4. Serverni ishga tushirish
npm run dev

  jadvallar avtomatik yaratiladi
